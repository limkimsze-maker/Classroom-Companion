What this test measures

The score describes this 24-item batch from this teacher. It is not a nationwide or classroom-wide accuracy estimate. Skipped items stay in the planned denominator. Fractions test spatial layout; letter case and written arithmetic are preserved.

Collect separate batches from several teachers and devices before drawing broader conclusions. Later improvements should use a separate set of handwriting; once these results guide a fix, this batch becomes development evidence.

Until you finish a real teacher batch, there is no natural-handwriting accuracy result. Synthetic checks used to test the page are not handwriting accuracy evidence.
