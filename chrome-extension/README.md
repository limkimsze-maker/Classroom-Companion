# Classroom Companion Launcher

A small Chrome extension that opens the existing Classroom Companion as a narrow teacher strip. It works from normal pages and Chrome New Tab because it launches from the extension action rather than a JavaScript bookmarklet.

## Install

1. Download and unzip the `chrome-extension` folder.
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the `chrome-extension` folder.
6. Pin **Classroom Companion Launcher** from the Extensions menu.

## Use

Click the pinned Classroom Companion extension icon. The launcher opens the live English Classroom Companion toolbar as a narrow popup strip on the left side of the current Chrome window. Clicking the icon again focuses the existing strip instead of creating duplicates.

The 16 tools and their code remain on the existing GitHub Pages app. The extension only changes how the toolbar is launched.
